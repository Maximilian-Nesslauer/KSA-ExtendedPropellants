# Extended Propellants

A data-only mod for Kitten Space Agency. It adds liquid propane (`ExtProp_C3H8`), the reaction liquid oxygen plus propane (`ExtProp_Propalox`, default mixture ratio 2.7) and a yellow and orange exhaust plume (`ExtProp_PropaloxPlume`). It has no parts and no code; other mods use it for their engines. Made for KSA build 2026.11.10.5801.

Enable it together with the mod that needs it. Without it, the engines of that mod do not load. On its own it changes nothing in the game.

For mod authors: the README of the repository has an XML example for an engine.
